Định hướng phát triển

Mục tiêu của mình là trở thành một Fullstack Developer chuyên nghiệp, có khả năng xây dựng các hệ thống web tin cậy, giao diện trực quan và hiệu năng cao.

Kiến thức & Công cụ trang bị

Những ngôn ngữ, framework và công cụ mình đang học tập và ứng dụng thực tế.

JavaScript

Lập trình tương tác, xử lý logic phía Client.

Cấu trúc dữ liệu & giải thuật, lập trình hướng đối tượng (OOP).

Cơ sở dữ liệu SQL

Thiết kế lược đồ quan hệ, truy vấn dữ liệu MySQL / SQL Server.

Git & GitHub

Quản lý phiên bản mã nguồn và làm việc nhóm hiệu quả.

Tư duy giải quyết vấn đề

Tìm kiếm tài liệu, giải quyết lỗi (debugging) và tự học nhanh.
