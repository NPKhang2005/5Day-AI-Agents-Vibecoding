## 🎯 Mục tiêu bài học (Objectives)
- Hiểu khái niệm cốt lõi về **AI Agents**: Điểm khác biệt giữa LLM truyền thống và Agent tự chủ (Autonomous Agent).
- Nắm bắt triết lý **Vibe Coding**: Cách cộng tác, đối thoại và định hướng cho AI để tạo ra mã nguồn nhanh chóng, trực quan.
- Làm quen với môi trường học tập trên Kaggle Notebooks và thiết lập API key (Gemini API / Google AI Studio).
- Thực hành xây dựng sản phẩm đầu tiên bằng phong cách Vibe Coding.
