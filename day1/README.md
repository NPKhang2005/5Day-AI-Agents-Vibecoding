# Buổi 1: Giới thiệu về AI Agents & Lập trình Vibe Coding

Chào mừng bạn đến với buổi học đầu tiên của khóa học **5-Day AI Agents: Intensive Vibe Coding Course With Google** trên nền tảng Kaggle!

## 📌 Chủ đề buổi học
**Giới thiệu về AI Agents & Lập trình theo phong cách Vibe Coding (Introduction to Agents & Vibe Coding)**

---

## 🎯 Mục tiêu bài học
- Nắm vững khái niệm nền tảng về **AI Agents**: Sự khác biệt giữa mô hình ngôn ngữ lớn (LLM) thông thường và Agent tự chủ (Autonomous Agent).
- Hiểu và ứng dụng phong cách **Vibe Coding**: Cách đối thoại, hướng dẫn và cộng tác cùng AI để xây dựng phần mềm nhanh chóng, trực quan.
- Làm quen với môi trường Google AI Studio, thiết lập khóa API và trải nghiệm sức mạnh mô hình Gemini.
- Thực hành xây dựng và triển khai ứng dụng web lên nền tảng đám mây Google Cloud Run.

### 🔹 Bài tập 1: Xây dựng Website giới thiệu bản thân bằng Vibe Coding
- **Thư mục bài làm:** [`bai-tap-1/`](./bai-tap-1/)
- **Mô tả chi tiết:**
  - Trang web giới thiệu bản thân: **Nguyễn Phúc Khang** - Sinh viên ngành Công nghệ Thông tin tại **Đại học An Giang (AGU)**.
  - Thiết kế hiện đại với gam màu xanh công nghệ chủ đạo, tương thích trên cả máy tính và điện thoại di động (Responsive).
  - Bao gồm các phần: Giới thiệu chung, Học vấn, Kỹ năng CNTT, Sở thích cá nhân và Biểu mẫu liên hệ.
- **Các tệp nộp bài:**
  - [`index.html`](./bai-tap-1/index.html): Cấu trúc trang web bằng HTML5.
  - [`style.css`](./bai-tap-1/style.css): Định dạng giao diện, màu sắc và hiệu ứng bằng CSS3.
  - [`script.js`](./bai-tap-1/script.js): Xử lý tương tác cuộn trang và form liên hệ bằng JavaScript.
