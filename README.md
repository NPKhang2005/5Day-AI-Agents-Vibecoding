## 🎯 Chi tiết từng buổi học

### 📁 [Day 1: Introduction to Agents & Vibe Coding](./day1/README.md)
- **Bài tập 1:** Xây dựng Website giới thiệu bản thân cá nhân bằng HTML/CSS/JavaScript.
- **Bài tập 2:** Ứng dụng tương tác **Snowflakes & Balloons** xây dựng qua Google AI Studio và triển khai lên Cloud Run ([Demo](https://khang-snowflakes-balloons.ai.studio)).

### 📁 [Day 2: Agent Tools & Interoperability](./day2/README.md)
- Cách trang bị và gọi công cụ (Tool Calling / Function Calling) cho Agent.
- Tương tác với API bên ngoài, khả năng tương tác liên hệ thống (Interoperability).
- **Bài tập 1:** Ứng dụng web Danh ngôn Bất hủ Song ngữ (Famous Quotes) xây dựng với **Antigravity CLI** (Flask + Vanilla JS, 100 câu danh ngôn, tìm kiếm, danh mục, lưu yêu thích, xuất CSV, Dark/Light mode, phát âm song ngữ, 12 tests passed).

### 📁 [Day 3: Context Engineering: Sessions, Skills & Memory](./day3/README.md)
- Kỹ thuật quản trị ngữ cảnh (Context Engineering).
- Quản lý phiên làm việc (Sessions), kỹ năng (Skills) và bộ nhớ dài hạn/ngắn hạn (Memory) của Agent.

### 📁 [Day 4: Agent Quality & Security](./day4/README.md)
- Đánh giá chất lượng đầu ra của Agent, kiểm thử tự động (Agent Evals).
- Bảo mật Agentic: phòng chống prompt injection, rò rỉ dữ liệu và kiểm soát quyền hạn an toàn.

### 📁 [Day 5: Prototype to Production](./day5/README.md)
- Đưa sản phẩm Agent từ bản thử nghiệm (Prototype) lên môi trường thực tế (Production).
- Triển khai, giám sát (Monitoring), tối ưu chi phí và độ trễ.
